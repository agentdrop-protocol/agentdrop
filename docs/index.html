1 · Hold an Agent ID

Agent ID is SPACE ID's non-transferable agent identity on BNB Chain. One per user — that's what makes one-claim-per-person enforceable on-chain.

2 · Connect & check

Connect any BNB Chain wallet. AgentDrop reads your Agent ID balance directly from the official SPACE ID contract — no sign-ups, no forms.

3 · Claim, once

Hit claim and the Pioneer NFT is minted straight to your wallet. The pool contract has no owner and no admin — nobody can move the rules after launch.
